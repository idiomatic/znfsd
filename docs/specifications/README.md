# Specifications

External specifications znfsd relies on.

| File | Title | Source | Why it applies |
| --- | --- | --- | --- |
| [rfc1813.txt](rfc1813.txt) | RFC 1813: NFS Version 3 Protocol Specification | <https://www.rfc-editor.org/rfc/rfc1813> | NFS v3 and, in its appendix, MOUNT v3 |
| [rfc5531.txt](rfc5531.txt) | RFC 5531: RPC: Remote Procedure Call Protocol Specification Version 2 | <https://www.rfc-editor.org/rfc/rfc5531> | ONC RPC message format, record marking, and AUTH_SYS |
| [rfc4506.txt](rfc4506.txt) | RFC 4506: XDR: External Data Representation Standard | <https://www.rfc-editor.org/rfc/rfc4506> | Encoding of every RPC message |
| [rfc1833.txt](rfc1833.txt) | RFC 1833: Binding Protocols for ONC RPC Version 2 | <https://www.rfc-editor.org/rfc/rfc1833> | Portmapper v2 and rpcbind v3 and v4 |
| Not collected (copyrighted) | Protocols for Interworking: XNFS, Version 3W (The Open Group, C702) | <https://pubs.opengroup.org/onlinepubs/9629799/toc.htm> | NLM v4 (lockd) and NSM v1 (statd) |
